# Sprint 2 · Patch 07 — UX Overhaul

## Product goal
처음 방문한 DJ가 Spotify 연결부터 Rekordbox Export까지 다음 행동을 잃지 않고 진행한다.

## Primary workflow
1. HOME — Spotify 연결
2. LIBRARY — Rekordbox XML 업로드
3. CANDIDATES — 후보곡 확인 및 보강
4. GENERATE — AI 세트 생성
5. EDIT — 순서·에너지·역할 및 실제 믹스 검토
6. EXPORT — Spotify / Rekordbox XML / M3U8
7. HELP — Rekordbox Import 및 USB Export 안내

## Compatibility
Patch 06의 XML Sync, Backup, Health Check, Missing Track Report 기능을 유지한다.
