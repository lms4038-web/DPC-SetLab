# Sprint 2 · Patch 08

## 목표

Home을 대시보드처럼 꾸미는 대신, **Landing → Onboarding → Workspace** 구조로 정보 구조를 분리합니다.

## 최초 실행 흐름

1. 독립형 랜딩 화면
2. 시작하기
3. Spotify 연결 또는 건너뛰기
4. Workspace 진입
5. Library에서 Rekordbox XML 업로드
6. Generate → Edit → Export

## 핵심 차이

- 랜딩에서는 사이드바와 상단 탭을 생성하지 않습니다.
- 기존 사용자는 `기존 작업 공간 열기`로 바로 진입할 수 있습니다.
- Settings에서 랜딩 화면을 다시 열 수 있습니다.
