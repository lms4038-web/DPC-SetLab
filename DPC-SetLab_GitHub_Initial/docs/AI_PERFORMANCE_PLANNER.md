# AI Performance Planner

## 데이터 우선순위
1. Rekordbox XML에 포함된 POSITION_MARK Cue
2. BPM과 곡 역할 기반 프레이즈 추정
3. 향후 Rekordbox 내부 Phrase 데이터 또는 로컬 음원 분석

## 시간 계산 원칙
- 사용자가 지정한 평균 곡 사용시간은 목표값이다.
- 실제 Mix In/Out은 8·16·32마디 경계로 정렬한다.
- 오프닝, 피크, 클로징은 길게 배분한다.
- 브리지/전환곡은 짧게 배분한다.
- 다음 곡과 겹치는 전환 마디는 세트 누적시간에서 제외한다.

## 신뢰도
- 높음: Cue가 3개 이상이며 적절한 Cue 구간을 찾음
- 중간: Cue 구간은 사용했으나 Cue 수가 제한적임
- 낮음: Cue가 없어 BPM과 역할만으로 추정함
